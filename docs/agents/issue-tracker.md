# Issue tracker: GitHub

Issues and PRDs for Buzzcode live in GitHub Issues in `ttizze/buzz-discord`. Always pass `--repo ttizze/buzz-discord` to `gh`; this checkout also has an upstream remote and automatic inference can select the wrong repository.

## Conventions

- Create, read, edit, label, comment on, and close issues with the `gh issue` commands and the explicit repository above.
- PRs are not a request or triage surface.
- When a skill says to publish to the issue tracker, create a GitHub issue in `ttizze/buzz-discord`.
- When a skill says to fetch a ticket, read the corresponding GitHub issue and its comments and labels.
