# Use unified outbound host connections

Local and remote agent execution will use the same Buzzcode Host protocol. The desktop app runs `buzzcode-host` locally for direct messages and personal projects, while every server Remote Environment runs one `buzzcode-host` service. Every Host establishes an authenticated outbound connection and executes authorized agent and file operations locally; the central service does not initiate SSH sessions or retain host SSH private keys. This avoids two integration stacks and supports Hosts behind NAT, at the cost of operating a Host process everywhere agents run.
