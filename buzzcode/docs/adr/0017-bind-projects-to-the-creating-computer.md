# Bind each Project to the Computer where its folder is added

A Project is added from a folder local to the Computer performing the creation, and records that Computer and folder without asking the user to enter a Project name or select a VPS, Remote Environment, Host, or repository. Selecting the folder creates the Project immediately, and the Computer supplies the selected folder's basename as the Project display name. Personal Projects remain owner-only while Server Projects share their metadata, Channels, and permitted file access with Server Members; file operations and Agent Runs route back to the bound Computer, whether it is a user's computer or a VPS. A Computer and its Host are not owned by one Server and may back explicitly shared Projects in multiple Servers. A Project remains visible and its Channels remain usable while that Computer is Offline, but its files and Agents are unavailable. Project Folders need not be Git repositories, and Git branches or worktrees are used only when the selected Agent normally uses them and the folder supports them. This treats a VPS as an always-available Computer rather than a distinct Project type, while making Project creation explicit consent to use that Computer for the shared Project.
