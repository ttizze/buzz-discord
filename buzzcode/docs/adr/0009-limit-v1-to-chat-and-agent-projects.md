# Limit v1 to chat and agent projects

Buzzcode v1 will deliver authentication, multi-server membership, fixed roles, open and private channels, flat replies, reactions, editing and deletion, one-to-one direct messages, personal and server projects, unified local and remote Agent Hosts, Codex and Claude Code streaming, search, archiving, and audit history. Forum, workflows, canvases, git hosting and CI, huddles, mobile clients, media uploads, personas, agent teams, and general cross-server user search are deferred so the first release can prove the core human-and-agent collaboration model end to end.
