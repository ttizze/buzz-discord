# Require server-admin-provided VPS infrastructure

Buzzcode v1 will not provision or resell compute for server projects. A Server Owner or Admin supplies one VPS, installs the Agent Host, pairs it with exactly one server using a one-time code, and configures project folders and available remote agents. Version 1 permits at most one host per server; that host may serve multiple projects but never another server. VPS and model-provider costs remain with the server operator, avoiding compute billing and abuse-management scope in the initial SaaS release.
